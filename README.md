# ItreeWebsite

Website der Itree, erstellt mit [Hugo](https://gohugo.io/).

## Theme

Diese Website verwendet das [Hugo Up Business](https://github.com/writeonlycode/hugo-up-business) Theme von [writeonlycode](https://github.com/writeonlycode). Es wird als Hugo-Modul eingebunden.

## Voraussetzungen

- [Hugo](https://gohugo.io/) (min. v0.147.8, Extended Edition)
- [Go](https://go.dev/) (v1.24+)
- [Node.js](https://nodejs.org/) (für Tailwind CSS)

## Lokale Entwicklung

```bash
npm install
hugo server
```

## Tech-Stack

- Hugo (Static Site Generator)
- Tailwind CSS v4
- Go Modules (für Hugo-Theme-Management)
