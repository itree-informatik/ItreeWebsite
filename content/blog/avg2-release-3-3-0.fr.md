La release d'automne 3.3.0 est prête à être installée. Elle apporte avant tout davantage de flexibilité dans le domaine stationnaire de longue durée – ainsi que trois nouveautés qui simplifient la gestion des personnes et des fichiers.
<!--more-->

## 🏠 Établissements individuels dans le domaine de longue durée

Avec la release d'été, nous avons introduit le [type d'établissement](/fr/blog/avg2-release-3-2-0/) : établissement, home ou organisme responsable. Dans le domaine stationnaire de longue durée, AVG2 supposait jusqu'ici une structure composée d'un organisme responsable et d'un home.

Désormais, les établissements du domaine stationnaire de longue durée peuvent aussi être gérés comme **établissement individuel, sans organisme responsable ni home** – comme dans les autres domaines de soins.

La fonction est désactivée par défaut. Elle peut être activée au besoin sous **Paramètres › Configuration**. Nous vous accompagnons volontiers dans cette démarche.

## 🔍 Recherche de personnes étendue

Sur la page Personnes des paramètres, vous pouvez désormais rechercher non seulement par adresse e-mail, mais aussi par :

- **prénom**
- **nom**
- **rôles** – avec sélection multiple

Les correspondances partielles sont également trouvées, et les critères peuvent être combinés librement.

## 📎 Gérer soi-même les types de fichiers et les extensions

Les types de fichiers se trouvent désormais sous **Paramètres**, où leur désignation peut être adaptée. Le nom d'un document généré est déterminé par la désignation du type de modèle Word.

Les extensions de fichier autorisées au téléversement – par exemple `.pdf` ou `.docx` – sont désormais définies par vos soins sous **Paramètres › Configuration**. Pour certains types de fichiers ou de documents, la liste peut en outre être restreinte. Les fichiers dont l'extension n'est pas autorisée sont refusés par AVG2 lors du téléversement.

## 👤 Ajouter des personnes – une seule manière pour tous les cas

Sur la page Personnes d'un établissement, il n'y a plus qu'un seul bouton : **« Ajouter »**.

- Si l'**adresse e-mail est connue**, la personne est reprise directement avec un rôle.
- Si elle est **inconnue**, vous saisissez la personne en un clic.

---

## Ce qu'il reste à savoir

Ce n'est qu'un extrait. La **liste complète de toutes les modifications** se trouve comme d'habitude, après l'installation, dans l'application sous **Paramètres › Releases**. Pour toute question, nous sommes volontiers à votre disposition.

> **En bref :** 3.3.0 rend AVG2 plus flexible dans le domaine de longue durée et vous donne davantage de contrôle sur les personnes et les fichiers.
